# 示例

## 示例 1：小范围 bug 修复回归

### 输入

用户说：修复了一个表单校验 bug，帮我判断开发后应该怎么测。

### 期望处理

- 分类为 bug 修复回归
- 影响面聚焦在表单逻辑和相关 API
- 风险一般为 P2 或 P1
- 路径以本地测试、类型检查、局部人工验证为主
- 不默认开启双 Agent

## 示例 2：跨系统状态改动

### 输入

用户说：改了订单完成后对权限解锁的逻辑，帮我出测试方案。

### 期望处理

- 分类为状态 / 权限 / 集成回归
- 风险至少 P0
- 需要主链路和重复触发边界路径
- 应建议模块测试 + 集成验证 + 真实环境验收
- 若工具可用，默认开启双 Agent

## 示例 3：发布前回归

### 输入

用户说：这周准备发布，请给我一个测试轮次方案。

### 期望处理

- 分类为发布前信心检查
- 要输出分任务、分轮次目录
- 必须完整走六步
- 应输出残余风险
- 可默认开启双 Agent，一个规划、一个执行
