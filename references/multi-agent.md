# 多智能体协作

只有当多智能体协作能明显提高吞吐或清晰度时才使用。

## 默认角色

### Planner Agent

负责：

- 识别意图
- 映射影响面
- 建模风险
- 选择验证路径

### Executor Agent

负责：

- 跑测试
- 收集证据
- 总结失败和跳过项

## 适合开启的场景

- 多系统改动
- 范围较广的回归规划
- 一个智能体做规划，另一个智能体执行有边界的清单

## 不适合开启的场景

- 很小的局部改动
- 重复执行
- 无边界的探索式 swarm

## 规则

`Planner Agent` 必须定义：

- 范围
- 成功标准
- 停止条件

`Executor Agent` 不应无故自行扩张任务边界。
