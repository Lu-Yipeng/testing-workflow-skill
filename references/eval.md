# 评估标准

这份 skill 自己也应该被评估。

## 基础评估问题

1. 是否正确分类了测试目标
2. 是否识别了主要影响面
3. 是否给出了合理风险等级
4. 是否给出了最小但有意义的验证路径
5. 是否正确判断了是否需要双 Agent
6. 是否避免把 benchmark 当主优化目标
7. 是否避免把纯探索当默认主路线
8. 是否产生了标准输出目录和文件

## 通过标准

一轮使用这份 skill 的过程，至少应满足：

- 六步有输出
- 输出目录结构正确
- 若满足条件，多智能体建议明确
- 若出现 bad case，有知识沉淀

## 失败信号

出现以下任一情况，说明 skill 需要继续改进：

- 只给原则，不给行动
- 只给命令，不给原因
- 不区分项目级和全局级边界
- 多智能体使用条件含糊
- 输出无法回放
